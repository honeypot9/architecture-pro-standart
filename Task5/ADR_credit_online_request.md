### <a name="_3bfxc9a45514"></a>**Функциональные требования**

| **№** | **Субьект** | **Сценарий**                           | **Описание**  |
|:-----:|:------------|:---------------------------------------|:--------------|
|1|Новый клиент|Подача заявки на кредит через сайт|1. Заходит на сайт банка<br>2. Просматривает кредитные продукты<br>3. Заполняет форму заявки (ФИО, паспортные данные, телефон, желаемая сумма)<br>4. Отправляет заявку<br>5. Получает мгновенное решение (одобрено/отказано)<br>6. При одобрении ожидает звонка из кол-центра для назначения встречи в отделении|
|2|Существующий клиент|Подача заявки на кредит через интернет-банк с предодобренным предложением|1. Авторизуется в интернет-банке<br>2. Видит персональное предодобренное кредитное предложение на главной странице<br>3. Просматривает условия кредита (сумма, ставка, срок)<br>4. Указывает счёт зачисления средств и данные для подачи заявки<br>5. Подтверждает операцию СМС-кодом<br>6. Отправляет заявку в банк<br>7. Получает уведомление о принятии заявки<br>8. Ожидает обработки в течение дня|
|3|Система кредитного скоринга|Предварительный расчет предодобренных предложений|1. Ежедневно в нерабочее время получает данные клиентов из АБС<br>2. Запрашивает кредитные истории из Бюро кредитных историй<br>3. Рассчитывает скоринг для каждого клиента<br>4. Формирует предодобренные предложения для клиентов с высоким скорингом<br>5. Сохраняет результаты в кэше для быстрого отображения|
|4|Система кредитного скоринга|Обработка онлайн-заявок из Kafka|1. Получает заявку из Kafka (от Credit Application Service)<br>2. Запрашивает кредитную историю из Бюро кредитных историй<br>3. Для существующих клиентов получает данные из АБС<br>4. Рассчитывает скоринг на основе доступных данных<br>5. Принимает решение (одобрено/отказано)<br>6. Одобренные заявки передает в Кредитный конвейер|
|6|Кредитный конвейер|Обработка одобренной заявки|1. Получает одобренную заявку от системы кредитного скоринга<br>2. Создает задачу для менеджера бэк-офиса кредитов<br>3. Менеджер проверяет условия и документы<br>4. При необходимости запрашивает дополнительные документы<br>5. Формирует кредитный договор<br>6. Уведомляет клиента о готовности договора<br>7. После подписания передает данные в АБС для выдачи кредита|
|7|Менеджер кол-центра|Консультация клиента по кредитной заявке|1. Получает уведомление о новой одобренной заявке<br>2. Просматривает детали заявки в системе кол-центра<br>3. Звонит клиенту для назначения встречи в отделении|
|8|Менеджер фронт-офиса|Выдача кредита в отделении|1. Встречает клиента с одобренной заявкой<br>2. Проводит идентификацию клиента (для новых клиентов)<br>3. Подписывает кредитный договор<br>4. Оформляет выдачу кредита в АБС<br>5. Выдает средства клиенту или переводит на счет|
|8|Credit Application Service|Прием и маршрутизация кредитных заявок|1. Принимает заявки с сайта и интернет-банка<br>2. Валидирует данные заявки<br>3. Передает ВСЕ заявки в Kafka для обработки системой скоринга<br>4. Сохраняет историю заявок|

### <a name="_qmphm5d6rvi3"></a>**Решение**

#### Принципы

1. Использование кредитного конвейера и системы скоринга
2. Event-Driven Architecture: Асинхронная обработка через Kafka для взаимодействия компонентов
3. API-First подход: интеграция с внешними системами по REST
4. Микросервисная архитектура: изоляция кредитного функционала в отдельные сервисы

#### Расширения существующих систем:

1. Модуль на ASP.NET MVC для отображения предодобренных предложений
2. Форма для подачи кредитных заявок новыми клиентами
3. Credit API Gateway: Java Spring Boot gateway для маршрутизации кредитных запросов

#### Технологический стек:

Backend Services: Java Spring Boot (для микросервиса)
Frontend: React.js (сайт), ASP.NET MVC (интернет-банк)
Database: MS SQL Server (основные данные), Redis (кэш)
Message Broker: Apache Kafka
Workflow Engine: Camunda BPM

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

1: Синхронная интеграция с кредитным конвейером
Риски: нагрузка на кредитный конвейер, сбой системного сервиса во время пиковой нагрузки

2: Расчет скоринга в реальном времени
Риски: высокая нагрузка на АБС, медленный отклик для клиентов из за запроса к БКИ

3: Прямая интеграция интернет-банка с кредитным конвейером
Недостатки: Нарушение принципа единой точки входа, дублирование механизма валидации
